The Parking Management System (PMS) is an Agile-based software project developed to streamline parking operations by managing vehicle registration, parking slot allocation, entry and exit tracking, fee calculation, payment processing, and report generation. The project follows the Scrum framework, using Trello for project planning and task management and GitHub for version control and documentation. Through requirement analysis, UML design, sprint planning, and testing, the project demonstrates real-world software project management practices while improving parking efficiency and reducing manual errors.
